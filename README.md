# 知忆

知忆是一款 Android AI 对话与长期记忆应用，帮助你保存聊天、整理历史，并在后续交流中检索相关记忆。

## 功能

- 多会话管理、角色头像、置顶与按最近对话时间排序。
- ZIP / JSON 聊天备份导入、会话预览、消息分支与后续消息切换。
- 历史记录分批总结、长期记忆、笔记整理与混合检索。
- 聊天、总结和向量模型独立配置；上下文设置最高 1,000,000 Token，实际受模型和服务限制。
- 本地数据保存、备份导出与恢复、字体缩放和日夜主题。

## 项目结构

- `web/`：界面与数据逻辑。
- `app/`：Android 工程及同步的网页资源。
- `tests/`：使用合成数据的自动化检查。

当前源码版本为 2.6。已保留最新会话排序与导入分支逻辑。数据库和备份格式的内部标识保留兼容性。

## 构建与验证

使用 JDK 17、Android SDK 35 和兼容的 Gradle 构建。正式签名通过环境变量提供。自动化检查可执行 `node tests/<测试文件>.cjs`；设备交互与外部服务需在实际环境验证。

## 隐私

此公开源码不携带个人聊天记录、个人备份、API 密钥或签名私钥。应用的导入、导出和备份是功能代码，个人数据由使用者自行管理。请勿将聊天、访问令牌或签名文件提交到公共仓库。
